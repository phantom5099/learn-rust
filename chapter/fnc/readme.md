# 函数

- Rust代码的函数与变量命名风格为所有字母小写并用下划线分隔单词
- 必须声明函数签名中每个参数类型

## 语句与表达式
- 语句: 执行操作但不返回值
  - `let x = 6;`是一个语句；
  - `fn`函数定义本身是语句
- 表达式: 计算并返回值
  - 表达式的结尾没有分号
  - if是表达式 `let number = if condition { 5 } else { 6 };`,注意每个分支的类型必须相同，否则无法通过编译

## 函数返回值
- 函数可以返回值
  - 使用`return`关键字返回值
  - 也可以省略`return`关键字，函数的最后一个表达式的值将作为返回值
  - 在箭头（->）后面声明它的类型 `fn foo() -> i32`
