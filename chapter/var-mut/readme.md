# 变量与可变性

## let的可变性
`
let x = 5;
x = 6;
`
不可通过编译，let定义的是一个不可变量
`
let mut x = 5;
x = 6;
`
可通过编译，mut声明x是一个可变量

## const--常量
- 常量是不可变的，只能被设置为常量表达式
- 常量必须在编译时就知道其值类型
- 不可使用mut
- 不可使用`let`重新赋值
- 对常量的命名约定是全部大写，并用下划线分隔单词

## 遮蔽
- 可以使用相同的名称遮蔽之前的值
- 遮蔽时，新的值会覆盖旧的值
- 遮蔽时，旧的值会被丢弃

## 复合类型

可把多个值组合成一个类型，原生有两种：

### 元组(tuple)
- 长度固定，声明后不得增长或者缩小
- 可以存储不同类型的值
- 不带任何值的元组叫做**单元**，它的类型是`()`，值也是`()`，若是一个表达式不返回任何值时，就会隐式返回单元值

### 数组
- 长度固定，声明后不得增长或者缩小
- 每个元素必须具有相同类型
- 在栈上分配的一整块、大小已知且固定的内存
