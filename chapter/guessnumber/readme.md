# 猜数字游戏

## 描述
对应官方文档的猜数字章节，用以记录初学状况

## 要点
- 导包语句：use package::module
- 可变变量定义：let **mut** arg
- ::与.的区别(io::stdin().read_line(&mut guess)):
  - :: 是命名空间/路径分隔符，用于模块、类型、静态项等
  - .是成员/方法访问符，用于具体实例的数据和方法
- & 是引用符号，用于借用数据而不获取所有权
- &mut 是可变引用符号，用于借用数据并获取所有权
- .expect(string) 是错误处理方法，用于在发生错误时打印错误信息(string)并退出程序
